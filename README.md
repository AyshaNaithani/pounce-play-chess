
PURRECT BOARD BATTLES - CAT CHESS

A fun and interactive chess game that combines the classic game of chess with a cute cat-themed design.


FEATURES:

- Classic chess gameplay
- Cat-themed chess pieces
- Play with a Friend mode
- Play vs Computer mode
- Chess timer
- Move history
- Captured pieces tracking
- Undo move option
- Restart game option
- Sound toggle
- Multiple cat themes
- Clean and responsive interface

GAME MODES:

1. Play with a Friend
   Play a local two-player chess match on the same device.

2. Play vs Computer
   Challenge the computer and practice your chess skills.

HOW TO PLAY:

1. Open the game.
2. Select your preferred cat theme.
3. Choose a game mode.
4. Select a chess piece.
5. Choose a valid square to move the piece.
6. Continue playing according to standard chess rules.
7. The objective is to checkmate the opponent's King.

CHESS PIECES:

Pawn - Moves forward and captures diagonally.
Knight - Moves in an L-shaped pattern.
Bishop - Moves diagonally.
Rook - Moves horizontally or vertically.
Queen - Moves horizontally, vertically, or diagonally.
King - Moves one square in any direction.

GAME CONTROLS:

- Undo: Undo the previous move.
- Restart: Restart the current game.
- Sound: Enable or disable game sounds.
- Timer: Tracks the remaining time for each player.

CAT THEMES:

- Cream Cats
- Black Cats

PROJECT GOAL:

The goal of this project is to create a fun and engaging chess experience while keeping the rules and strategy of traditional chess. The cat-themed design makes the game more entertaining and visually appealing.
